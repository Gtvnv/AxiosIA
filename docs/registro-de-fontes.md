# Registro de Fontes

Cada Fonte avaliada com os [critérios de confiança](criterios-de-confianca.md) recebe uma linha nesta tabela. Fontes descartadas permanecem registradas.

- **formato:** `vídeo`, `artigo` ou `pdf`.
- **status:** `aprovada` ou `descartada`.
- **motivo:** para `aprovada`, os nomes de pelo menos 3 critérios atendidos, incluindo autoria identificável e acesso público. Para `descartada`, os nomes dos critérios não atendidos, ou "Dado Pessoal", "compartilhamento não permitido" ou "link inacessível" com a data da verificação.
